# Research material

Source material for drafting site content — not part of the built site itself (nothing
here is read by Astro's content collections in `src/content/`).

- `academy-material/` — extracted notes from the Covington Mayor's Academy program
  (sessions, speakers, dates, topic-specific briefings). Read these when drafting a new
  `src/content/academy-notes/*.md` entry.
- `civic-notes/` — `CIVIC-NOTE-TEMPLATE.md` and `CIVIC-VOICE-GUIDE.md` are the
  structure/voice/hard-rules guide every `src/content/civic-notes/*.md` entry follows
  (see `docs/GUARDRAILS.md`'s Civic Notes section too). `MEETING-SCHEDULE.md` has
  Covington's recurring civic-meeting facts.

Moved out of the retired `mcp/*` agent system's `.remember/` directory on 2026-08-29 —
this is real content research Jerry uses when writing, independent of any tooling.
